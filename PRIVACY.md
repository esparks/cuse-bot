# cuse-bot Privacy Policy

cuse-bot does not collect, store or share personal information about Reddit
users.

- **What it stores:** game schedules from ESPN, and the IDs of the posts it
  created (so it doesn't post twice and knows which posts to sticky). This
  is stored in Reddit's Devvit app storage for r/cuse.
- **Outside requests:** the only one is reading public schedule data from
  ESPN (site.api.espn.com). No user data is sent anywhere.
- **No tracking:** it doesn't read, log or analyze user activity, votes,
  comments or messages.

Questions go to the r/cuse moderators via modmail.
